The site should be redesigned to align with the brand.

A design system already existed, and the site was in breach of its single most explicit rule. Studio Matte lives in ngw-leadgen/docs/brand/, dated 2026-08-15, with every contrast pair already measured. Its light spec ends: “No warm gold. No pink. No neon teal. No blue.” The site was neon teal on navy. This was not a redesign — it was a re-skin onto a system that was already written.

The accent is the brand, so it belongs on every section.

“The accent, used once.” The landing reference states the discipline in four words. Steel had been on every section kicker, a 3px rule across every card, 64px ghost numerals and five check glyphs. It is now on actions only; kickers dropped to the metadata tier, where the Role Ladder says a kicker belongs.

The contact form's catch block renders the success state on failure.

True but not the fault that fired. The catch was never reached: fetch resolves on a 404, so the success call ran from the try path. A gate written against the catch alone would have gone green the moment someone deleted it, while every message was still discarded.

Corrected 2026-09-23 by a dispatched audit, then verified empirically — fetch returned ok=false without throwing

Three gates are blind — they passed while their faults were reintroduced.

One blind gate and two inert faults. verify:copy had genuinely stopped seeing its subject when React began emitting the year as separate text nodes with HTML-comment separators, so it passed on every page while measuring nothing. The other two faults never fired: one wrote a concatenation expression instead of a literal, the other emptied files the framework still emits. An exit code cannot tell those apart, which is why each fault now prints the bytes it changed.

Corrected 2026-09-23 during the red-proof sweep · 6 of 6 now RED

The site loads analytics — tracker strings appear in the shipped chunks.

Zero analytics, zero cookies. Every match was framework internals: "segment" is Next's App Router route segments, gTag is Symbol.toStringTag. No Set-Cookie on any page.
